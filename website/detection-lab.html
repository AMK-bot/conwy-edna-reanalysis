Change the survey and biological conditions. The simulation knows the truth; the analyst sees only detections. It deliberately lets sequencing depth and the hidden ecological gradient vary together, echoing the recoverability problem found in the Conwy reprocessing.

What this model does - and does not - show

The synthetic data contain 800 site-time units. Occupancy varies along a hidden biological gradient. Sequencing depth can follow the same gradient. The “depth-only correction” assumes detection is a fixed function of depth and estimates only a constant occupancy, so it cannot see the biological part of the gradient. It is an instructional likelihood calculation, not the project’s production occupancy model.

  • Reads are not abundance: PCR, primer affinity, biomass and library construction all affect read counts.
  • Non-detection is not absence: repeated samples reduce, but never erase, the chance of missing a present taxon.
  • Correction is not automatic truth: when depth is entangled with biology, a depth term can attribute genuine ecological structure to sampling failure.
