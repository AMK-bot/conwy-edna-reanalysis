# Cached public input: Salmo multi-marker benchmark

Retrieved from NCBI Nucleotide on 2026-07-19 by `scripts/fetch_salmo_multimarker.py`. Queries were accession-sorted, limited to 50 non-RefSeq mitochondrial records of 15,000--20,000 bp per frozen submitted label, and then audited from raw GenBank records. Only records with exact organism annotations, complete-mitogenome wording, a unique MiFish-U product, and complete unambiguous COI/cyt-b windows could enter the common-accession panel.

The query receipts retain every returned UID and official summary. Raw GenBank files are cached only for records assessed before five passing accessions were selected; later query candidates remain visible in the accession manifest as not assessed. Public organism names are submitted annotations, not independent biological truth. RefSeq derivatives and partial-marker substitutions are deliberately excluded.
